# ACEat — подготовка к SAT

Четыре модуля: учебники, демонстрационный ИИ-чат по темам, архив прошлых экзаменов и авторские Challenge-экзамены.

Сайт: https://the-fabulous.github.io/ACEat/

## Самостоятельный драйвер учебников

Вся логика обработки скопирована внутрь ACEat в `textbook_engine/`. Это самостоятельная копия алгоритмов Classifi: не нужны соседняя папка, API Classifi, загрузка его исходников или LangGraph. Происхождение кода описано в `textbook_engine/ORIGIN.md`.

Драйвер запускается автором вручную и создаёт готовый учебник:

```text
PDF → book_driver.py → textbook_engine/ → data/books/<id>-<хеш>.json
                                      → data/catalog.json
                                      → вкладка «Учебники» → #book/<id>
```

Посетители читают заранее созданные главы. Открытие сборника или учебника не запускает Python, генерацию или запросы к AI. Локальная панель и эндпоинты импорта удалены.

### Три полных PDF в сборнике

Каждый источник скачан целиком и обработан отдельным последовательным запуском существующего `book_driver.py --mode contents`:

| Источник | Страниц PDF | Глав ACEat | Страницы оглавления |
| --- | ---: | ---: | --- |
| Eben Roux — The Complete SAT Mathematics Practice Book | 362 | 11 | 4 |
| Erica L. Meltzer — The Critical Reader, 2nd edition | 358 | 14 | 7–10 |
| Erica L. Meltzer — The Ultimate Guide to SAT Grammar | 441 | 19 | 6–7 |

Драйвер создаёт новые учебные объяснения по темам оглавления. Полные исходные PDF хранятся локально в игнорируемой `.local/sat-sources/`; в читалке есть ссылки на них. Это материалы ACEat, подготовленные с ИИ. Два издания Meltzer относятся к бумажному SAT, что указано в карточках; сведения о формате экзамена в них устарели. Источники, объём, диапазоны оглавления и SHA-256 записаны в `data/textbook-sources.json`.

Режимы драйвера — прежние `contents` и `pages`. Единственная поправка обработки: распознавание номеров глав `1.`, `1:` и чтение колонок оглавления в визуальном порядке. Короткие первоначальные пособия заменены этими тремя страницами.

### Подготовка окружения

Нужен Python 3.10+ и зависимости только этого проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-import.txt
```

Скопируйте `.env.example` в локальный `.env`, добавьте ключ вашего AI-провайдера. Поддерживаются `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `GEMMA_MODEL`; переменные среды имеют приоритет. Драйвер читает только `.env` ACEat, никогда конфигурацию из Classifi. `.env` игнорируется Git. Ключ не передаётся на сайт.

### Создать страницу учебника

Из корня ACEat:

```powershell
.venv\Scripts\python.exe book_driver.py "C:\Books\sat.pdf" --id sat-math --title "SAT Math" --subject math --start-page 2 --end-page 4
```

Или используйте короткую обёртку с теми же аргументами:

```powershell
.\build-book.cmd "C:\Books\sat.pdf" --id sat-math --title "SAT Math" --start-page 2 --end-page 4
```

Дополнительные аргументы: `--author`, `--description`, `--subject math|reading|mixed`, `--mode contents|pages`, `--replace`, `--publish`.

Номера страниц считаются с единицы по порядку в PDF, независимо от печатной нумерации. ID: строчные латинские буквы, цифры и дефисы, начинается с буквы, до 64 символов. Исходный PDF можно хранить вне проекта или внутри игнорируемой папки `.local/`.

- `--mode contents` (по умолчанию): выберите страницы нумерованного оглавления. Драйвер извлечёт главы/подтемы и создаст учебные объяснения по их названиям. Это новые материалы по темам, а не полный текст или точный пересказ книги. Поддерживаются арабская/римская нумерация глав и нумерованные подтемы.
- `--mode pages`: обработка текста выбранных страниц Math, объяснение навыков и новые примеры. Для других направлений используйте оглавление.

Нужен текстовый PDF; OCR сканов не включён. Лимит одного запуска — 500 выбранных страниц; большие фрагменты лучше обрабатывать частями.

Учебник автоматически добавляется в каталог и открывается в читалке с оглавлением, переходами между главами и формулами. При повторном ID драйвер требует `--replace`. Если генерация прервётся, старый каталог сохраняется, а готовые главы остаются в игнорируемом `.local/cache/`. Повторите команду с теми же параметрами для продолжения из кэша. Публикуйте только проверенные материалы, которые разрешено размещать открыто.

### Проверить и опубликовать

```powershell
node preview.mjs
```

Откройте http://127.0.0.1:4173/#textbooks. Внутри вкладки есть раскрываемая инструкция «Как добавить учебник». Читалка использует ссылки `#book/<id>/<номер главы>`.

После проверки повторите команду драйвера с флагом `--publish`. Он зарегистрирует готовый учебник, создаст коммит только каталога и связанных JSON и выполнит `git push origin main` без force. Нужен настроенный Git-доступ к `The-Fabulous/ACEat`. Если уже есть staged-изменения, публикация остановится. Без `--publish` драйвер только подготавливает локальные файлы.

Можно также вручную закоммитить `data/catalog.json` и нужные файлы `data/books/`, затем выполнить push. После сборки GitHub Pages книга появится в публичном сборнике. Оригинальный PDF драйвер на сайт не копирует.

## Данные и совместимость

В `data/catalog.json` три независимых массива: `textbooks`, `pastExams`, `challengeExams`. Книги драйвера имеют `id`, `title`, `subject`, `author`, `description`, `source`, `chapter_count`, `book_path`, `url`. Формат JSON `aceat.classifi-book.v1` и маркер `format: classifi` сохранены для совместимости с уже созданными материалами; эти имена не обозначают внешнюю зависимость.

Обычные внешние материалы можно добавлять объектами с `title`, `subject`, `description`, `source` и `url`. Допустимы относительные адреса или HTTP(S). Текст выводится безопасно как текст. Формулы обрабатываются MathJax с safe-расширением; при недоступности CDN остаются текстом.

Импорт учебников не меняет архивы экзаменов и не подключает демонстрационный ИИ-чат. Чат пока использует подготовленные примеры и не сохраняет историю после перезагрузки.

## GitHub Pages

**Settings → Pages → Deploy from a branch → main → / (root)**. Сборка приложения не нужна, `.nojekyll` отключает Jekyll. Сайт — статические HTML/CSS/JS и подготовленные JSON. Шрифты загружаются из Google Fonts с системным fallback.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check app.js
node --check preview.mjs
git diff --check
```

Тесты покрывают обработку PDF, обе стратегии генерации, сохранение каталога при ошибках, кэш и замену, защиту публикации. Отдельный тест запускает настоящий `book_driver.py` в изолированной копии ACEat без папки Classifi, с тестовым локальным AI-сервером. Платных AI-запросов и настоящего push тесты не делают.
