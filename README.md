# ACEat — четыре модуля подготовки к SAT

Статический интерфейс на HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

Сайт: https://the-fabulous.github.io/ACEat/

## Модули

1. `#textbooks` — сборник учебников, поиск по названию/описанию/автору, фильтры Math и Reading & Writing. Импортированные книги открываются в читалке `#book/<id>/<номер главы>` с оглавлением и формулами.
2. `#chat` — макет ИИ-чата: пять тем, готовые объяснения, примеры и частые ошибки. Свободный ввод демонстрирует интерфейс; сообщения не отправляются на сервер. Модель и ключ API не подключены.
3. `#past-exams` — заготовка архива прошлых экзаменов, ссылка на официальную практику College Board.
4. `#challenge` — заготовка библиотеки авторских экзаменов с планируемой сложностью выше SAT. Варианты ещё не добавлены, их сложность не проверена.

Главная `#home` показывает все четыре модуля. Прямые ссылки и кнопки браузера «Назад»/«Вперёд» работают через hash-маршруты, включая GitHub Pages в подпапке репозитория.

В ранней версии каталоги пусты. Отображаемые числа отражают содержимое каталога. Демонстрационный чат не сохраняется после перезагрузки и сбрасывается при переключении темы. Проект не связан с College Board.

## Добавление материалов

Данные находятся в `data/catalog.json`. Массивы `textbooks`, `pastExams` и `challengeExams` наполняются независимо. Минимальный объект содержит непустой `title`. Остальные поля:

```json
{
  "title": "Название материала",
  "subject": "math",
  "author": "Автор",
  "year": "2026",
  "description": "Краткое описание",
  "source": "Название источника и сведения о публикации",
  "url": "./materials/example.pdf"
}
```

`subject`: `math`, `reading` или `mixed`. `url` может вести на локальный файл в репозитории или HTTPS-страницу. Пустое значение показывает статус подготовки. Загружайте только проверенные материалы, разрешённые к публикации; реальные прошлые экзамены и авторские упражнения помещайте в соответствующие отдельные массивы.

## Импорт PDF через Classifi

Classifi подключён как отдельный движок из соседней папки `../Classifi`. Используется его актуальный конвейер `extract_book_contents.py` → `generate_topic_pages.py`. Код движка не копируется в ACEat и его `materials/` не изменяется. Нужна версия Classifi с коммитом `93d232d` или новее.

1. Убедитесь, что рядом находятся папки `ACEat` и `Classifi`. Для другой папки задайте `CLASSIFI_DIR` или `--engine-dir`.
2. Используйте Python-окружение Classifi. Если оно ещё не подготовлено, установите зависимости: `python -m pip install -r requirements-import.txt` (Python 3.10+).
3. Настройте ключ в существующем `Classifi/.env` или отдельном локальном `ACEat/.env`. Поддерживаются `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `GEMMA_MODEL`; переменные среды имеют приоритет. Значения ключа не передаются браузеру и не публикуются.
4. Дважды нажмите **start-library.cmd**. Либо запустите `..\Classifi\.venv\Scripts\python.exe manage_library.py` из папки ACEat. Панель откроется на http://127.0.0.1:4174/manage.html.
5. Выберите текстовый PDF до 25 МБ, название, стабильный ID, направление и диапазон страниц PDF (считая с единицы, независимо от печатной нумерации книги).
6. Нажмите **Обработать через Classifi**. После завершения откройте и проверьте учебник в локальном сборнике.
7. Нажмите **Опубликовать на GitHub Pages**. Панель создаст коммит только каталога и связанных JSON книг и выполнит обычный `git push origin main` без force. После сборки Pages учебник будет доступен всем. Если в Git уже есть staged-изменения, публикация остановится, чтобы не включить чужую работу. Требуется настроенный доступ к GitHub через Git.

Панель на публичном Pages содержит пояснение о локальном запуске: GitHub Pages не исполняет Python и не обрабатывает PDF.

### Два режима

- **Оглавление → учебные главы** (основной): выберите только страницы с нумерованным оглавлением. Classifi извлечёт темы и подтемы и создаст новые объяснения по ним. Это не пересказ или извлечение полного содержания книги: генератор работает по названиям тем. Поддерживаются нумерованные главы/подтемы, в том числе римская нумерация глав. При неподходящем оглавлении импорт останавливается с сообщением.
- **Текст страниц → материал Math**: обрабатывает выбранный фрагмент существующим `Classifi/import_book.py`. Создаёт объяснения навыков и новые примеры по математическим заданиям из страниц. Для Reading & Writing используйте режим оглавления. Полную книгу лучше обрабатывать частями; лимит одного запуска — 500 выбранных страниц.

В обоих режимах нужен текстовый PDF. OCR сканов не включён. Исходник временно хранится в `.local/uploads/` и удаляется после обработки; готовые главы сохраняются в `.local/cache/` для повторного запуска после сбоя. Весь `.local/` игнорируется Git и не обслуживается локальным сервером.

Готовый учебник сохраняется в `data/books/<id>-<хеш>.json`, получает запись в `data/catalog.json`, ссылку `#book/<id>` и атрибуцию источника/версии Classifi. Добавление учебника сохраняет архивы экзаменов; повторный ID требует явной замены. При ошибке генерации старый каталог остаётся неизменным. Изменение каталога публикуется атомарно после записи всех глав; прежние версии JSON сохраняются.

Через командную строку:

```powershell
..\Classifi\.venv\Scripts\python.exe -m tools.library C:\Books\sat.pdf --id sat-math --title "SAT Math" --subject math --mode contents --start-page 2 --end-page 4
```

CLI только готовит локальные файлы. Для публикации используйте кнопку панели или закоммитьте `data/catalog.json` и нужные файлы `data/books/`, затем выполните push.

Браузерная читалка показывает заголовки, абзацы, шаги, ключевые выводы и математические формулы. При недоступности CDN MathJax формулы остаются текстом. Свободный AI-чат остаётся демонстрационным — импорт книг не подключает его автоматически.

## Локальный просмотр

Из папки проекта:

```sh
node preview.mjs
```

Открыть http://127.0.0.1:4173. Сервер привязан только к loopback и предназначен для локального просмотра. Шрифты загружаются из Google Fonts; при недоступности используются системные.

## GitHub Pages

В репозитории `The-Fabulous/ACEat`: **Settings → Pages → Deploy from a branch → main → / (root)**. Файл `.nojekyll` отключает Jekyll. После push GitHub публикует `index.html`, `style.css`, `app.js` и `data/catalog.json`.

## Проверка

```sh
node --check app.js
node --check preview.mjs
node --check manage.js
..\Classifi\.venv\Scripts\python.exe -m unittest discover -s tests -v
git diff --check
```

Тесты используют собственный короткий PDF и подменяют ответы AI. Они проверяют настоящий конвейер Classifi, регистрацию и чтение книги, сохранение старых данных при сбое, повторный запуск из кэша, явную замену, блокировку параллельных операций, локальный HTTP-импорт и защиту приватных файлов. Внешних запросов к модели и push тесты не делают.

Перед публикацией проверьте четыре раздела, прямые ссылки, поиск и фильтры, читалку глав, панель импорта и демонстрационный чат на компьютере и телефоне.
