# ACEat

Простая адаптивная веб-страница для подготовки к SAT на HTML, CSS и JavaScript, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере. При наличии Python можно запустить локальный сервер командой `python -m http.server 8000` из папки проекта и открыть http://localhost:8000.

## Возможности

- Направления Math и Reading & Writing.
- Шесть учебных вопросов с проверкой и объяснением ответа.
- Счётчик верных ответов за текущую сессию; повторный просмотр не увеличивает счёт.
- Адаптивный интерфейс для телефона и компьютера.

Прогресс хранится только в памяти страницы и сбрасывается после перезагрузки. Вопросы созданы для демонстрации, не являются официальными материалами SAT. Проект не связан с College Board. Шрифты загружаются из Google Fonts; без интернета используются системные шрифты.
