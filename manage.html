Открой локальную панель

Запусти start-library.cmd из папки ACEat на своём компьютере. Панель откроется по адресу http://127.0.0.1:4174/manage.html.

GitHub Pages показывает готовые учебники. Обработка PDF выполняется на твоём компьютере через Classifi.

Новый учебник

01 / IMPORT

Выбери страницы оглавления: Classifi извлечёт темы и создаст учебные объяснения. Это новые материалы по темам книги, а не полный текст оригинала.

Оригинальный PDF не публикуется. Для генерации темы или выбранный текст передаются AI-провайдеру из локальной конфигурации Classifi. Публикуй только материалы, которые разрешено размещать открыто.

02 / REVIEW

Ход обработки

Здесь появятся текущая глава и результат обработки.

Открыть учебник ↗

Если генерация прервётся, повтори загрузку с теми же настройками. Готовые главы будут взяты из локального кэша.

03 / PUBLISH

Опубликовать сборник

После проверки отправь каталог и готовые главы в репозиторий The-Fabulous/ACEat.
